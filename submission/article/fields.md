Title (max 255 characters):
A travel-booking agent that cannot search or book unless you tell it where and when

Description (max 512 characters):
A travel-booking agent built with Strands Agents and Amazon Bedrock that guards every tool call -- search and booking -- with Strands Decider 2B. If any argument (city, dates, traveller count) was not stated by the user, the agent asks a follow-up question instead of guessing. At the median, the decider answers in 295 ms at zero cost, 4.3x faster than asking the LLM the same question.
